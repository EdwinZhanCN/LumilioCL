# 0037 — 用户路径表由代码注释生成

- Status: in_progress
- Phase: Phase 8 — ARCH 页面接入和视觉验收
- Author: agent

## Goal

`docs/ia/` 里“已实现的用户路径”不再手写：实现处写 `// ia[page]: …` 注释，`lumilio-docgen` 生成 `docs/ia/paths/<page>.md`，状态由“注释存在”推出（ADR 0019）。手写 IA 只保留页面定位、层级草图、未做项和范围外。

## Scope

- In scope：`crates/lumilio-docgen`（扫描、校验编号、生成、`--check`、与手写表对照）；每页迁移：给代码加注释 → 生成 → 和手写表对照 → 订正代码或文档 → 删手写的已实现行；迁移时顺手把该页的混合文件拆开。
- Out of scope：层级/组件清单的生成；未做项的生成；AGENTS.md 验证命令不加第五条（用 `cargo test` 里的过期检查）。

## Tasks

- [x] T1: docgen 骨架：解析、校验、渲染、`--check`、`compare`，带测试。
- [x] T2: 试点：游戏库（拆文件留到各页迁移完后统一做，见 Outcome）。
- [ ] T3: 首页、导航、动态、发现、账户。
- [ ] T4: 设置、游戏页（概览/内容/世界/历史/诊断/设置）。
- [ ] T5: 清理：删除 `compare`，AGENTS.md / IA README / skills 写入注解约定。

## Validation

四项检查；每页对照结果记在 Outcome（手写多出的、代码多出的、各自怎么处理）。

## Outcome

- 游戏库：21 条注解。对照结果：手写 15 行中 14 行与代码一致；手写多出 0 条“代码没有”的路径，除了把“合集：新建/改名/删除/加入/移出”合并成一行（代码里是三个入口）；代码多出 7 条手写没有的路径（菜单里的开始游戏/打开/设为当前游戏、打开游戏库文件夹、从合集拆出的三项等）。顺带发现两处文案和实现不符并已修：空合集提示说“在卡片上点合集”（卡片上只有 ⋯ 菜单里的“加入合集…”），空收藏提示说“点收藏”（现在是星标）。
- 生成表按源码顺序排列，不是按用户流程顺序；需要时再加排序注记。
