## 明确没做

- 离线皮肤（H-ACC-11）：ADR 0018 提议推迟，等维护者决定第三方认证范围。
- CurseForge 整合包：需要 API 密钥。
- 第三方认证（authlib-injector）、启动器自动更新。
- 整合包更新（识别包管理文件）。
- 恢复模式界面、数据迁移、未完成安装/更新的恢复、进程失联接管、跨卷删除（见 `docs/workflows/state-and-recovery.md`）。
