# cubiomes snapshot

Upstream: https://github.com/Cubitect/cubiomes
Baseline: `e61f90580cbdd883214a8054670dacae655e59c0`.
License: MIT, Copyright (c) 2020 Cubitect; see [LICENSE](LICENSE).

Imported: generation C sources and headers, `rng.h`, `tables/`, README and LICENSE.
Omitted: `quadbase.*` (seed search and threads), `tests.c`, docs and build files.

## Local patches

- 2026-10-09: explicit Minecraft Java release identities for 1.21.5–26.3;
  new Overworld parameter tables for 1.21.5, 26.2 and 26.3, generated by
  `cargo xtask cubiomes-btree` from original-game numeric trees. Tables for
  1.21.5–26.1.2 are shared only after comparing every release's tree.
- Variable subtree boundaries preserve 26.3's original search order, including
  its irregular branches. Older tables keep the upstream search path.
- Added sulfur caves (187, 26.2) and dappled forest (188, 26.3), with names,
  version gates and local map colours.
- Updated woodland mansion and stronghold biome rules from per-release tags.
  Added 26.3 abandoned camp region placement and an estimated biome filter.
  Camp markers are region candidates: surface height and template offsets are
  not simulated. The Rust adapter marks them as estimated.
- Original saved-world spawn checks expose a 20-block baseline discrepancy
  for seed -123456789012345. Native spawn coordinates remain unchanged; the
  adapter now marks spawn estimates in every release, including 1.18+.

Sources, hashes, differences and reproduction commands are in [data](data/README.md).
The host-owned bridge lives in `crates/lumilio-cubiomes/src/bridge.c`.
The upstream baseline and MIT attribution are retained.

## Automated verification (2026-10-09)

Every release has its own original-server hash, parameter tree and goldens.
Across the 1.21.4 baseline and all twelve new releases, 44,928 runtime biome
samples match. The public map API is additionally checked at block Y=64.
All twelve new releases match 15,375 original regional placement samples and
the changed stronghold, mansion, trial-chamber and camp biome tags.

39 disposable vanilla worlds provide 706 saved Anvil biome samples,
159 `/locate` results and 39 spawn estimates. Camps are checked against the
region grid; spawn predictions are checked within the documented search area.
Older biome/structure C-probe goldens also pass. Numeric trees for 1.21.4
reproduce all 9,112 upstream node words.

Full `just check` passes: build, workspace tests, Clippy and formatting.
Validation used `CARGO_INCREMENTAL=0 DISPLAY=:99` in the managed Linux
environment; Windows/MSVC was not covered by that run.

The maintainer confirmed game verification on 2026-10-09, including the F3
and `/locate` review required by W14. Automated samples cover their tested
points and do not claim exhaustive terrain simulation.
