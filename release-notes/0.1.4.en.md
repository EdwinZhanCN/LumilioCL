0.1.4 brings game settings presets, automatic Java downloads and a fuller seed map, and makes the schematic 3D preview closer to the game. From this version on, the first start after an update shows what changed.

## New

- Game settings presets: several games share one set of keys, mouse, sound, language and video options, managed in Library › Presets. For each option you change in the game, you decide whether it stays with that game, updates the preset or goes back to the preset's value.
- While a game is closed, you can change its options in the game's Settings › Options.
- When no installed Java fits, starting a game and installing Forge or NeoForge download one first, show the progress in Activity and then continue.
- Oracle GraalVM is a new download source, with Java 21 and 25.
- Each game can choose its Java in Settings › Java: Automatic (recommended), a Java the launcher found, or a custom path. The setting says which Java the next start uses.
- The seed map adds bastion types, igloo basements, End ships, nether fossils, copper and iron veins, ravines and the enchanted golden apples in desert pyramids, up to 26.3.
- A modpack can install a chosen version from its version list.
- The first start after an update shows what changed, and Settings › About opens it again.

## Improvements

- Java is chosen by game version, loader and system. If the Java you chose cannot run a version, the launcher asks once before it starts, and the answer applies to that start only.
- The launcher finds Java in more places: the runtimes of the official launcher and the Microsoft Store, java on PATH, and the install folders of common vendors.
- Settings › Java downloads Java by major version and removes Java the launcher downloaded itself.
- The schematic 3D preview loads 26.3 resources in about 0.1 s instead of several seconds.

## Fixes

- In the schematic 3D preview, chests and banners that face east or west are no longer mirrored, both halves of a double chest meet, and the textures of turned stairs, walls and fences line up with the world.
- In the schematic 3D preview, banners and the book on an enchanting table no longer show missing textures, and the colours of leaves, bushes and redstone wire and the shading of plants and water match the game.
- A schematic file the preview cannot read now says so, instead of reporting that the preview thread crashed.

## About this update

- Download Java on launch is on by default. Turn it off in Settings › Java if you do not need it.
- Fossils and surface lava lakes on the seed map are estimates: the candidate positions are exact, but the terrain checks are not modelled yet.
