0.1.3 让主页打开更快，修复 Windows 上的黑色控制台窗口，并完善 macOS 自动更新的重启。

## 改进

- 主页先显示你的游戏，诊断在后台补充，不再等检查完才出现内容。

## 修复

- Windows 上启动游戏、运行启动钩子和安装 Forge / NeoForge 时，不再弹出黑色的控制台窗口。
- macOS 自动更新覆盖 App 时跳过 Finder 的图标文件，并防止重启时再开一个新实例。

## 更新说明

- 从 0.1.2 自动更新到 0.1.3 时，由 0.1.2 的新逻辑先等待旧进程退出再重新打开，Dock 中只保留一个 LumilioCL。
- 从 0.1.1 或更早版本更新时仍由旧逻辑执行，可能出现第二个 Dock 图标；退出两个窗口后重新打开即可，App 已是 0.1.3。
