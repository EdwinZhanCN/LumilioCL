0.2.1 给发现页加上中文翻译：开启后简介自动显示简体中文，项目正文点一下就能翻译。发现页的结果改为紧凑的列表行，一屏能看到更多项目。新增半透明主题 Glass 与 Tinted Glass，以及 Birch、Deepslate 两套主题；首页只讲当前游戏。启动失败时首页直接说出原因，启动器的错误也会记进日志文件。一次导入多个游戏不再失败；游戏目录被删或移走时，启动器会说明，不再启动一个空游戏。

## 新功能

- 发现页翻译：在设置 › 通用里开启「翻译」后，发现列表和项目详情页头的简介自动显示简体中文，标题保留原文。翻译默认关闭。
- 简介译文先用 MCIM 的中文简介，MCIM 没有时用 launcher.lumilio.org 的机器翻译；查询时只发送平台和项目 ID。Modrinth 和 CurseForge 的项目都能翻译。
- 项目正文：点安装键左边的翻译键，用所选的翻译提供商（目前是微软 Edge）译成简体中文，代码、链接和图片保持原样；再点一次显示原文。翻译失败或只译出一部分时保留原文，可以重试。
- 译文在本机保存 7 天，可以在设置 › 通用里清除翻译缓存。
- 半透明主题：新增内置主题 Glass（浅色）与 Tinted Glass（深色），窗口后面的桌面经过模糊透出来；按键、显示屏、对话框、菜单和导航保持不透明。在 macOS 上效果最好；不能模糊的系统改用不透明的近似色。
- 新增内置主题 Birch（暖色米白）与 Deepslate（偏冷石板灰）。
- 主页壁纸可以选「不用壁纸」：标题与「继续」直接放在页面上，配合半透明主题时透出的桌面最多。
- 启动器日志：启动器自己的警告和错误写进数据目录的 `logs/launcher.log`，弹出的错误连同技术详情、启动失败和游戏非正常结束都记在里面。在设置 › 关于点「启动器日志」可以找到这个文件，导出的诊断包也会附上它。

## 改进

- 发现页的结果改为紧凑的列表行：名称和作者一行，简介一行，标签一行；右边是下载量（按关注数排序时是关注数）和日期，一屏能看到更多结果。
- 窗口较窄时，筛选栏收进排序方式左边的「筛选」键，键上显示已选几项，点开就能筛选。
- 窗口较窄时，导航条右边只显示账户头像和当前游戏的封面，不再盖住中间的首页、游戏库等按键；完整的游戏名在悬停提示里。
- 当前游戏只有一个：「继续」启动它，发现页装进它，导航芯片显示它。在芯片里选择、从游戏页浏览内容、从卡片或游戏页启动，都会让那个游戏成为当前游戏。
- 首页只讲当前游戏，不再列出「最近」的其他游戏；换游戏用导航芯片，浏览用游戏库。
- 启动失败后换了当前游戏，首页改为继续新的游戏，失败的那个出现在「需要留意」里。
- 游戏启动中也不能点「重启以更新」，不只是游戏运行时。
- 启动失败后，首页的恢复面板直接说出原因，例如账户需要重新登录、没有能运行这个游戏的 Java；不知道原因时仍说停在哪一步。
- 不在首页时启动失败或游戏意外退出，也会弹出错误提示。
- 游戏页、项目页和游戏设置里的提示改由主窗口统一显示，离开页面后仍能看到结果，例如删除游戏成功。
- 网络错误的技术详情写出具体原因，例如 DNS、TLS、连接被拒或超时。
- Microsoft 登录时，验证码出现后先自动复制，再打开验证页面，在浏览器里直接粘贴就行；弹窗仍显示验证码，也能手动复制。
- 半透明主题下，主页的方块世界和图片壁纸底部会融进玻璃，导航下面不再叠出一条深色带。
- 主题文件里只有页面、面板和分隔线可以半透明；其他颜色带透明度时按不透明显示，外观设置会说明。

## 修复

- 发现页筛选栏里点加载器的「显示更多」，不再连带展开「高级排除」。
- 换账户、删除账户或改 Java 设置后，首页「需要留意」立即更新，不用重启启动器。
- 从游戏卡片启动失败后，「恢复并继续」重试的是同一个游戏，不再启动之前的当前游戏。
- 启动没有成功时，提示改为「上次启动没有成功」，不再说「上一次游玩没有顺利结束」。
- 主题文件里带透明度的页面颜色现在真的会透出窗口，以前整个窗口仍是不透明的。
- 首页恢复面板的「技术详情」以前点了没有反应，现在打开可以复制的原始原因；游戏在启动时退出或崩溃时，打开这个游戏的诊断页。
- 后台工作意外中断时显示失败和技术详情，界面不再一直停在进行中，例如发现页卡片停在安装中、首页停在启动中。
- 在启动器里停止的游戏不再算作崩溃；在 macOS 和 Linux 上被系统信号结束的游戏算作崩溃。
- 从 PCL、HMCL 等启动器的 `.minecraft` 导入游戏时，按版本文件里的库识别加载器，游戏版本也从版本文件读取；`26.3-Fabric 0.19.5` 这类名字的游戏不再被当成原版。
- 从其他启动器的 `.minecraft` 一次选中多个游戏导入时，名字只差中文等字符的游戏（例如 `26.3` 与 `红石生电优化26.3`）不再有一个导入失败；同时复制游戏、导入整合包或恢复备份时也一样。
- 游戏目录在启动器外被删除或移走时，不再悄悄启动一个空游戏：游戏页和首页的「需要留意」会说「游戏目录不见了」，可以新建空目录；按「继续」时先询问，可以作为空游戏启动、查看游戏或取消。新建的游戏会立即有自己的目录。
