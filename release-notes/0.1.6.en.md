0.1.6 adds the schematic studio: view, count, replace and convert schematics in a separate window, and preview them even when the game is not installed. The world and server lists now show each type of information in its own way, and server MOTDs use the game's colors and a pixel font.

## New

- Schematic studio: the Schematics panel on the game page is now a gallery of thumbnails. Open a schematic to see it in a separate window. You can slice the viewport and hold Ctrl/⌘ to select a box. Materials and replacements count only the current slice or the selection.
- The block assets come from a resource bundle that the launcher downloads. The bundle covers releases 1.13.2 to 26.3, so you can preview schematics in a game that is not installed. Entities in schematics are drawn too.
- You can replace blocks in a schematic with a mapping table of many rows, and save the table as a scheme. You can also convert a schematic to a different game version. Blocks that the game version does not have are marked, with suggested replacements. By default, a conversion saves a new file.
- In the studio's resource sources, you can add mods, resource pack zips and resource pack folders, and change their order for each game.
- The studio's History panel lists the changes and all the backups. You can restore a backup even if the change log does not show it.

## Improvements

- The Worlds tab, its server list, Continue playing on Home and the Library show each type of information in its own way: status is an indicator light, versions and properties are tags, times and player counts are at the end of the row, and latency is green signal bars. Worlds show their game mode and whether cheats are on.
- Server MOTDs show next to the server name, with the game's colors and styles, in the Monocraft pixel font.
- The schematic header shows the version of the schematic and of the game. If the schematic does not record its version, the header shows "Version unknown" and does not guess. If some blocks cannot be drawn, the header shows how many block kinds have no model.
- In the game's Content tab, the update button on each row is now an icon button. Hover over it to see the version that it updates to.
- The install page on the website now tells you how to open an unsigned package for the first time.

## Fixes

- The launcher now uses zip 9.0.3 to read and write archives. This replaces the old version that crates.io yanked.

## About this update

- The first time the studio previews a game version, it must download the block assets from the network. If the server does not have the assets yet, the studio tells you so, and does not tell you that you have no network.
