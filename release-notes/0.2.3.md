0.2.3 主要修复 Windows 上的问题：多连接下载不再失败，导入整合包时会写入配置覆盖，启动前、包装和退出后命令按原样执行。从 Modrinth 装的正式版内容不再被提示更新到测试版。游戏与账户切换列表可以滚动和搜索，设置里的长路径从中间省略，可以复制。

## 改进

- 游戏与账户切换列表：列表太长时在弹层里滚动。项目较多时顶部有搜索框，打开就能输入，按名称、版本、加载器或账户类型筛选，按 Enter 选中第一项。
- 长路径：本地主题、数据目录和游戏的自定义 Java 路径保持一行、从中间省略，悬停显示完整路径，旁边的复制键复制完整路径。设置 › Java 列表里的路径也从中间省略，⋯ 菜单里可以「复制路径」。游戏页设置 › Java 里「将使用 Java …」这一行同样从中间省略，悬停显示整句。
- 设置里较长的值在自己的位置换行，不再把左边的名称挤没、和它叠在一起。
- 界面文案按简明语言规则改写：ⓘ 提示都只有一行，设置、账户与皮肤、启动命令、Rosetta 和游戏目录丢失等处的说明更直接。移除填了自定义 UUID 的离线账户时，会提醒以后重新添加要填回同一个 UUID。

## 修复

- Windows：多连接下载不再在最后一步报「拒绝访问。(os error 5)」。以前在默认设置下，从支持分段下载的来源下载较大的文件会失败，例如安装 Forge 时的依赖库。
- Windows：导入整合包时会写入整合包里的配置覆盖（overrides），以前这部分会丢失。
- Windows：启动前和退出后命令按原样交给 cmd，命令里的引号不再被破坏；包装命令里的路径（例如 `C:\Tools\wrap.exe`）保持完整。
- Windows：世界地图的缓存可以正常使用，不再每次都重新绘制。
- 从 Modrinth 装的正式版内容只提示正式版更新，不再提示测试版；没有适用于这个游戏的正式版时，才会提示测试版。
- 导入整合包后会直接打开新游戏并设为当前游戏。以前游戏库开着加载器筛选时，新游戏可能被筛掉，看起来像没导入。
- 开着翻译时，发现页的部分 Mod 详情页不再让启动器崩溃。
- 开着翻译时，刚启动时发现页里已翻译的简介不再变回原文。
