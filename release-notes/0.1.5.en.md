0.1.5 adds CurseForge as a content source: browse and install mods, modpacks, resource packs and shaders from CurseForge on the Discover page. The launcher also uses less memory: it no longer keeps growing after you look at maps and screenshots, and it releases memory when a game starts.

## New

- CurseForge content source: at the top of the Discover filter bar, switch between Modrinth and CurseForge. Search, filters, details and installs use the selected source.
- CurseForge modpacks: install one from Discover, or click Import modpack in the Library and choose a CurseForge .zip file.
- If an author allows a file to be downloaded only on the website, the launcher first looks for the same file on Modrinth. If it is not there, the launcher gives you the download page. The missing files of a modpack are listed in the game's Content tab; download them, then click "Add downloaded files…" to put them in place.
- The game's Content tab also recognizes mods from CurseForge, and checks for updates and switches versions through their source.
- The website has a new [user guide](https://launcher.lumilio.org/en/docs/guide/) and a [theme studio](https://launcher.lumilio.org/en/docs/guide/theme-studio/): make a theme in the browser, see a preview while you change it, then download the theme file.

## Improvements

- When a game starts, the launcher releases pictures and covers that are not on screen, and the game and project pages in its history, so that the game gets the memory. You can still go back to main pages such as Library and Discover.
- Screenshots and pictures are read at the size they are shown at. Large pictures no longer stay in memory at full size.

## Fixes

- After you look at the world map, screenshots and project pages, the launcher's memory no longer keeps growing.

## About this update

- The CurseForge source is on by default. To turn it off, go to Settings › Plugins.
