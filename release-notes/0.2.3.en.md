0.2.3 mostly fixes problems on Windows. Downloads on more than one connection no longer fail, an imported modpack now gets its configuration overrides, and Before launch, Wrapper and After exit commands run as you typed them. Content from Modrinth that is a release is no longer offered a beta as its update. You can scroll and search the game and account lists, and long paths in Settings are shortened in the middle and you can copy them.

## Improvements

- Game and account lists: when a list is too long, it scrolls in its panel. When there are many items, a search box shows at the top. You can type immediately to filter by name, version, loader or account type, and press Enter to select the first item.
- Long paths: local themes, the data folder and a game's custom Java path stay on one line and are shortened in the middle. Hover over a path to see all of it, and use the copy button next to it to copy all of it. The paths in Settings › Java are also shortened in the middle, and the ⋯ menu has Copy path. In a game's Settings › Java, the "Will use Java …" line is also shortened in the middle, and you can hover over it to see all of it.
- A long value in Settings now wraps in its own space. It no longer pushes the name on the left to zero width or covers it.
- The launcher text follows plain-language rules. Each ⓘ hint is now one line, and the text in Settings, accounts and skins, launch commands, Rosetta and the missing game folder is more direct. When you remove an offline account that has a custom UUID, the launcher tells you to type the same UUID again if you add the account again.

## Fixes

- Windows: downloads on more than one connection no longer fail at the last step with "Access is denied. (os error 5)". Before, with the default settings, a large file from a source that supports downloads in parts failed, for example the libraries for a Forge installation.
- Windows: when you import a modpack, the launcher now writes its configuration overrides. Before, they were lost.
- Windows: Before launch and After exit commands go to cmd as you typed them, so quotes in a command are no longer changed. A path in a Wrapper command (for example `C:\Tools\wrap.exe`) stays complete.
- Windows: the world map cache now works, so the map is no longer drawn again each time.
- Content from Modrinth that is a release is offered only releases as updates, not betas. A beta is offered only when no release works with the game.
- After you import a modpack, the launcher opens the new game and makes it the current game. Before, when the Library had a loader filter, the filter could hide the new game, and the import looked like it did not occur.
- With translation on, some mod pages in Discover no longer make the launcher crash.
- With translation on, translated summaries in Discover no longer change back to the original text after the launcher starts.
