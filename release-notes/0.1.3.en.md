0.1.3 opens Home faster, stops the black console windows on Windows and makes the macOS update restart cleaner.

## Improvements

- Home shows your games first and fills in diagnostics in the background, instead of waiting for every check.

## Fixes

- On Windows, starting a game, running launch hooks and installing Forge or NeoForge no longer open a black console window.
- A macOS update skips Finder's icon file when it replaces the app, and the restart no longer opens a second copy.

## About this update

- An automatic update from 0.1.2 to 0.1.3 uses 0.1.2's new logic: it waits for the old process to quit before reopening, so the Dock keeps one LumilioCL.
- An update from 0.1.1 or earlier still uses the old logic and can leave a second Dock icon. Quit both windows and open LumilioCL again; the app is already 0.1.3.
