0.2.2 makes downloads more reliable. All downloads share one connection limit, an interrupted download continues where it stopped, you can pause a running download, large files download in parts at the same time, and Activity shows the progress and source of each file. When a game quits as soon as it starts, the launcher shows the error that the game printed, and the output of each launch stays in the game's logs folder. NeoForge 1.21.4 modpacks, versions before 1.19 on Apple silicon, and versions 1.7.2 and earlier now start correctly.

## New

- Downloads continue: when a download is interrupted or cancelled, or all its sources fail, the downloaded part stays. Click Retry in Activity to continue from where it stopped. Parts that are not continued for 7 days are removed when the launcher starts.
- Pause and resume: in Activity, you can pause a running download. A paused download gives back its connections and keeps the downloaded part. Click Resume to continue from where it stopped.
- Large files download in parts: when the source supports it, a large file downloads several parts at the same time on free connections. When other downloads wait for a connection, the borrowed connections are given back immediately.
- Download details in Activity: while a task downloads, the top of the list shows the total speed and the connections. Each task row shows its status, its game, its progress and how much is downloaded. Click Details to see the files that are downloading, their sources and their retries. When a file changes to another source, the list says so.
- Output of each launch: the launcher writes everything that the game prints during a launch to `logs/lumilio-output.log` in the game folder, and keeps only the last launch. In a game's Diagnostics › Logs, it is called Last launch output. When the last launch failed and there is no crash report, View logs in the history opens it. An exported diagnostics bundle also includes it, with the player name removed.

## Improvements

- Downloads at once in Settings › Downloads & storage is now a limit for all downloads together. Before, it was a limit for each task. The automatic value is now 16 everywhere, and a change applies immediately, without a restart.
- Launcher updates also use the same downloads: they continue where they stopped and download in parts, and the launcher still checks them against SHA256SUMS. Requests for information such as the version list also share the connection limit, and retry or change to another source when they fail.
- When a game quits before it writes its log, Technical details on Home's recovery panel shows the last 50 lines (at most) that the game printed, and you can copy them. The error message that shows when you are not on Home, and the launcher log, also include these lines.

## Fixes

- NeoForge 1.21.4 modpacks no longer quit as soon as they start. When a loader library and an older copy from the game are both present, only the version that the loader lists is used. You do not have to install the game again.
- On Apple silicon, versions before 1.19 (for example 1.6.4) no longer quit as soon as they start. These versions have only Intel native libraries, so the launcher uses an Intel Java under Rosetta 2, as the official launcher does, and downloads it from Mojang if necessary. If Rosetta 2 is not installed, the launcher tells you how to install it. Versions 1.19 and later still use the native Java.
- Versions 1.7.2 and earlier no longer report that `game_assets` is missing when you download or start them.
- With the Glass and Tinted Glass themes, the cover at the top right of a game's page now fades into the background. It is no longer a rectangle that is lighter than the page and has hard edges.

## About this update

- If you set Downloads at once manually before, the number now limits all downloads together. You can change it in Settings › Downloads & storage.
