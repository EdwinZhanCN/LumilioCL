0.2.1 adds Chinese translation to Discover: when it is on, summaries show in Simplified Chinese, and you can translate a project's description with one click. Discover results are now compact list rows, so more projects fit on the screen. New translucent themes, Glass and Tinted Glass, let the desktop show through, and Birch and Deepslate are new built-in themes. Home now shows only the current game. When a launch fails, Home tells you why, and the launcher now writes its errors to a log file. Importing several games at once no longer fails, and when a game's folder is deleted or moved, the launcher tells you instead of starting an empty game.

## New

- Discover translation: turn on Translation in Settings › General. Summaries in the Discover list and in the project page header then show in Simplified Chinese. Titles stay as written. Translation is off by default.
- Summaries come from MCIM's Chinese summaries first. If MCIM does not have one, they come from launcher.lumilio.org's machine translation. Only the platform and the project ID are sent. Projects from Modrinth and CurseForge can both be translated.
- Project descriptions: click the translate button to the left of the install button. The selected translation provider (now Microsoft Edge) translates the description into Simplified Chinese. Code, links and images do not change. Click the button again to show the original. If the translation fails, or only part of it is translated, the original text stays and you can retry.
- Translations are kept on this computer for 7 days. You can clear the translation cache in Settings › General.
- Translucent themes: the new built-in themes Glass (light) and Tinted Glass (dark) let the blurred desktop show through the window. Buttons, displays, dialogs, menus and the navigation stay opaque. They look best on macOS; where the system cannot blur, they show an opaque colour close to them.
- New built-in themes: Birch (a warm cream) and Deepslate (a cool slate).
- Home wallpaper has a No wallpaper option: the title and Continue sit on the page. With a translucent theme, the most of the desktop shows through.
- Launcher log: the launcher writes its own warnings and errors to `logs/launcher.log` in the data folder. The log keeps each error that the launcher shows, with its technical details, and each failed launch and each game that stopped incorrectly. Click Launcher logs in Settings › About to find the file. An exported diagnostics bundle also includes it.

## Improvements

- Discover results are now compact list rows: the name and the author on one line, the summary on one line, and the tags on one line. At the right are the downloads (or the followers, when you sort by followers) and the date. More results fit on the screen.
- In a narrow window, the filter sidebar moves into the Filters button to the left of the sort order. The button shows how many filters you selected. Click it to filter.
- In a narrow window, the right side of the navigation bar shows only the account face and the current game's cover. It no longer covers the Home, Library and other buttons in the center. The tooltip shows the full game name.
- There is one current game. Continue starts it, Discover installs into it, and the navigation chip shows it. Choosing a game in the chip, browsing content from a game's page, and starting a game from its card or page all make that game the current game.
- Home shows only the current game. It no longer lists other recent games. Use the navigation chip to change the game, and the Library to browse.
- If a launch fails and you then choose another current game, Home continues the new game. The game that failed shows in Needs attention.
- Restart to update is also unavailable while a game starts, not only while it runs.
- When a launch fails, the recovery panel on Home tells you the cause, for example that the account must sign in again, or that no installed Java can run the game. If the cause is not known, it still tells you the step where the launch stopped.
- When a launch fails or a game quits unexpectedly while you are not on Home, an error message shows.
- The messages from a game's page, a project's page and the game settings now show in the main window. You still see the result after you leave the page, for example when a game is deleted.
- The technical details of a network error now give the cause, for example DNS, TLS, a refused connection or a timeout.
- Microsoft sign-in: when the code shows, the launcher copies it first and then opens the sign-in page. Paste the code in the browser. The dialog still shows the code, and you can still copy it manually.
- With a translucent theme, the bottom of Home's pixel world and of a picture wallpaper fade into the glass, and no dark band shows under the navigation.
- In a theme file, only the page, panels and lines can be translucent. Other colours with opacity show as opaque, and Settings › Appearance says so.

## Fixes

- In the Discover filters, Show more under Loader no longer also opens Advanced exclusions.
- After you change or remove the account, or change the Java settings, Needs attention on Home updates immediately. You do not have to restart the launcher.
- If a game started from its card fails to launch, Recover and continue tries the same game again. It no longer starts the game that was current before.
- When a launch does not succeed, the message is now "The last launch didn't succeed", not "The last session didn't end cleanly".
- A theme's translucent page colour now shows through the window. Before, the whole window stayed opaque.
- Technical details on Home's recovery panel did nothing before. Now they open the original cause, which you can copy. When the game exited while it started, or crashed, they open the game's diagnostics page.
- When background work stops unexpectedly, the launcher shows the failure and its technical details. The screen no longer stays in progress, for example a Discover card that stays at installing, or Home that stays at starting.
- A game that you stop in the launcher is no longer a crash. On macOS and Linux, a game that a system signal ends is a crash.
- When you import games from the `.minecraft` folder of PCL, HMCL or another launcher, the loader comes from the libraries in the version file, and the game version also comes from the version file. A game with a name such as `26.3-Fabric 0.19.5` is no longer imported as vanilla.
- When you select more than one game to import from another launcher's `.minecraft` folder, games whose names differ only in characters such as Chinese (for example `26.3` and `红石生电优化26.3`) no longer make one import fail. The same applies when you copy games, import modpacks or restore backups at the same time.
- When a game's folder is deleted or moved outside the launcher, the launcher no longer starts an empty game without telling you. The game's page and Needs attention on Home say that the game folder is missing, and you can create an empty folder. When you click Continue, the launcher asks first: play with an empty folder, view the game, or cancel. A new game now gets its folder immediately.

## About this update

- When MCIM does not have a translated summary, launcher.lumilio.org translates it in the background. The first time you see the summary, it can still be in the original language. Look again a bit later to see it in Chinese.
