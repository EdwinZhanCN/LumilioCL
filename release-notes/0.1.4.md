0.1.4 带来游戏设置预设、自动下载合适的 Java 和更完整的种子地图，并让投影 3D 预览更接近游戏。从这个版本起，更新后第一次打开会显示这次的更新内容。

## 新功能

- 游戏设置预设：多个游戏共用一套按键、鼠标、音量、语言和画面等选项，在游戏库 › 预设里管理；游戏里改过的选项由你决定只留给这个游戏、更新预设还是改回预设的值。
- 游戏关着时，可以在游戏页 › 设置 › 选项里直接修改这个游戏的选项。
- 没有合适的 Java 时，启动游戏和安装 Forge / NeoForge 会先自动下载一个，进度在动态里，装好后继续。
- 新增 Oracle GraalVM 下载来源，提供 Java 21 和 25。
- 每个游戏可以在设置 › Java 里选择自动（推荐）、已发现的 Java 或自定义路径，并写明下次启动会用哪个 Java。
- 种子地图新增堡垒遗迹的类型、雪屋的地下室、末地船、下界化石、铜矿脉和铁矿脉、峡谷，以及沙漠神殿里的附魔金苹果，支持到 26.3。
- 整合包可以在版本列表里安装指定的版本。
- 更新后第一次打开时显示这次的更新内容，设置 › 关于里可以再看。

## 改进

- 按游戏版本、加载器和系统选择 Java；手动选的 Java 运行不了这个版本时，启动前会问一次，回答只影响这一次。
- 能发现更多位置的 Java：官方启动器和 Microsoft Store 自带的运行时、PATH 里的 java，以及常见厂商的安装目录。
- 设置 › Java 可以按大版本下载 Java，也可以删除启动器自己下载的 Java。
- 投影 3D 预览加载 26.3 资源从数秒缩短到约 0.1 秒。

## 修复

- 投影 3D 预览里朝东、朝西的箱子和旗帜不再左右镜像，双箱的两半正确相接，转向的楼梯、墙和栅栏的贴图与世界对齐。
- 投影 3D 预览里旗帜和附魔台上的书不再显示缺失贴图，树叶、灌木、红石线的颜色和植物、水面的明暗与游戏一致。
- 读不懂的投影文件会说明“读不懂这个投影文件”，不再显示预览线程崩溃。

## 更新说明

- 启动时自动下载 Java 默认开启，不需要时可以在设置 › Java 关闭。
- 种子地图里的化石和地表岩浆湖是估算位置：候选位置准确，但还没有模拟地形检查。
