0.2.4 lets you run different games at the same time. The Content tab now shows the files first and keeps what it identified on your computer, so it does not wait for the content sources each time. While a game runs, you can copy, back up, export and delete the worlds that the game does not have open.

## Improvements

- Different games can run at the same time. While a game starts or runs, you can start another game from Home or the Library, and you can end each game on its own. Home shows the state of the current game. When you change back to a game that runs, Home shows the state of that game. When "When the game starts" is set to Hide launcher, the launcher hides when the first game starts to run, and comes back only after the last game ends. You cannot run the same game two times at once yet.
- Content tab: when you open it, it first shows the files in the folder, then the sources that it identified before, and then it asks the content sources again. While it asks, the toolbar shows "Identifying sources…". The launcher keeps what it identified for each file on your computer, so the next time it identifies only new files and old results. With no network, the tab still shows the sources that it identified before. The refresh button identifies all files again.

## Fixes

- While a game runs, only the world marked Playing cannot be copied, backed up, exported or deleted. Other worlds work as usual, and you can import a new world. Before, you could not change any world while the game ran.
- In the Content tab, when you turn a mod on or off, its switch and file name change immediately. Before, they changed only after the content sources identified the files, and sometimes they changed back.
- When the system language and the launcher language are different, the recovery message at start-up now uses the launcher language. Before, it used the system language.
