# Synthetic Xaero samples

Hand-written from the line format described in `src/xaero/waypoints.rs`, not
exported from a game. They exercise the parser (escaped colon, `~` for no Y,
emoji, a second set, death points, an unknown line, CRLF endings). They do not
prove how a given Xaero's Minimap version writes its files: plan W17 asks for a
sample exported by the pinned 26.x release, which still has to be added here.
