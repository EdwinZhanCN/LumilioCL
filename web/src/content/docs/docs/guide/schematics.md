投影工作室打开游戏 `schematics` 文件夹里的 `.litematic` 文件。
可以查看 3D 模型和材料，也可以改动文件。每次改动前，启动器都先备份原文件。

## 适用范围

- 只读写 Litematica 的 `.litematic` 文件，只读写这个游戏的 `schematics` 文件夹和其中的子文件夹。
- 支持 1.13.2 及以后的正式版的方块和实体。
- 工作室来自 **Litematica 投影** 插件。插件默认打开，可以在 **设置 › 插件** 里关闭。

## 准备

1. 在游戏里装上 Litematica 模组，或把 `.litematic` 文件放进游戏的 `schematics` 文件夹。
2. 打开游戏页的 **插件** 标签，选择 **投影**。

只有空的 `schematics` 文件夹、又没装 Litematica 时，不显示 **投影**。

游戏页上是投影的目录：每份投影一张卡片，带缩略图。选一张卡片，点 **打开工作室**（或双击卡片），工作室在自己的窗口里打开这份投影。

### 方块资源

预览需要游戏的方块贴图、模型和实体形状。它们来自启动器从 launcher.lumilio.org 下载的方块资源包，包含 1.13.2 到最新正式版的每个版本：

- 资源包只下载一次，校验后保存在启动器的数据文件夹里。
- 下载显示在 **动态** 里，名称是“准备 … 的方块资源”，进度按字节显示，可以取消。
- 没有网络、资源包又没下载过时，视口里有一句说明。服务器能连上、却还没有这份资源时，说明里写明网络没有问题。

不想自动下载时，关闭 **设置 › 下载与存储 › 自动下载方块资源**。
关闭后启动器不再下载；已经下载过的资源包照常使用。

### 模组和资源包

这个游戏的模组、已启用的资源包和你添加的资源包都列在 **信息 › 技术信息 › 资源来源** 里，每一行有一个开关：

- 开关默认关。打开后，视口叠上它重新绘制；优先级是：添加的资源包 > 资源包 > 模组 > 基础版本。
- 开关按游戏和投影文件夹记住，重新打开窗口后保持。
- 每一行写它提供多少种方块，以及有多少个模型用了自定义加载器、画不出来。

要叠加不在游戏里的资源包：在 **资源来源** 里点 **添加资源包…**，选一个 `.zip` 文件。
启动器只记下文件的路径，不复制文件。要去掉它，在那一行点 **移除**；文件本身不动。

## 工作室窗口

- **头部**：文件切换器（缩略图、文件名，点开是可搜索的文件列表）；尺寸与版本（例如“1.20.1 投影 · 游戏 26.3”，两个版本相同时只写一个）；橙色键 **替换方块…**；**更多** 菜单里有 **转换版本…**、**导出 PNG…**、**导出材料清单（CSV）**、**编辑信息…**、**在访达中显示**（按系统命名）和 **删除…**。
- **视口**：3D 模型。底部是工具条，上方的读数板写指针下的方块。
- **材料面板**：顶部的搜索字段和方块统计，下面是 **材料**、**信息**、**历史** 三个标签。

游戏运行时不能改动投影，相关的菜单项和键置灰，提示里写明原因。

## 查看投影

### 视口

- **Orbital**：拖拽旋转，滚轮缩放，方向键旋转，`+` / `−` 缩放。
- **Explore**：点画面或按 Enter 捕获鼠标，WASD 移动，空格上升，Shift 下降，Esc 释放鼠标。捕获中画面中心有准星。
- **角度** 里有北、东、南、西、顶、等轴六个预设。在 Explore 里选预设时，视口先切回 Orbital。
- **复位视角** 回到初始视角。
- 这个版本画不出的方块画成紫黑相间的缺失贴图整块，形状仍然完整。

### 检视一个方块

在 Orbital 里单击一个方块（不拖拽），或在 Explore 捕获中单击准星对着的方块。
这个方块描出边，检视卡浮在它上方，随视角移动：

- 名字、方块 ID 和坐标，每个属性一个标签（悬停看原文 `key=value`）。
- 容器按游戏界面的格子排出物品，悬停看名字与组数；告示牌和命令方块写出文字。
- **选中这种** 在 **材料** 里选中这种方块；**替换…** 打开替换方块，从这个方块的状态开始。

点到空处、按 Esc 或点检视卡的关闭键，放开这个方块。

### 材料

**材料** 标签里每种方块一个格子：图标和数量，最多的在前。悬停看名字和组数（例如“1 组 + 22”）。

- 悬停格子时，视口里这种方块保持原色，其余变淡。
- 点格子选中这种方块，面板底部出现详情：名字、ID、数量、每种方块状态的数量，以及 **替换…** 和 **只看这种**。
- 游戏版本没有某些方块时，头部有橙色标签“26.3 没有的方块：3 种”和 **转换到 26.3…**；这些格子右上角有 ✕，打开 **只看不兼容** 后只剩这些格子。

### 切片

点工具条的 **切片**，视口只画一层及以下，切口露出这一层的顶面。

- 用 **X** / **Y** / **Z** 换轴；用 ‹ › 键，或在视口里按 `[` 和 `]`，一层一层往下或往上。
- 读数写当前的轴和层号，以及这一层有多少方块；**材料** 只数这一层。
- 再点 **切片** 关闭。

### 框选

在 Orbital 里按住 Ctrl（macOS 上是 ⌘），从一个方块拖到另一个方块。两块之间的长方体被选中：边上画出一圈，里面略带颜色。

- **材料** 顶部写“选区 4×3×6 · 52 块”，格子只数选区里的方块。
- 点 **清除选区**，或在视口里按 Esc，回到整份投影。
- 有选区时打开 **替换方块…**，范围默认是这个选区。

### 信息

**信息** 标签里有名称、作者、描述和时间（点 **编辑…** 修改），实体列表，重复的文件，以及收起的 **技术信息**（数据版本、资源来源等）。

### 导出 PNG

1. 在 **更多** 里选 **导出 PNG…**。
2. 填宽和高，每边 1 到 4096 像素。
3. 选背景：**面板色** 或 **透明**。
4. 选角度：**当前视角** 或六个预设之一。
5. 点 **导出**，在保存对话框里选位置。

### 导出材料清单

在 **更多** 里选 **导出材料清单（CSV）**，在保存对话框里选位置。
清单按数量从多到少排列，带“组数”一列。

## 改动投影

每次改动都按同样的顺序进行：

1. 启动器把原文件复制到它自己的备份文件夹（在启动器的数据文件夹里，不在游戏文件夹里）。
2. 启动器确认文件在读取之后没有被别的程序改过。被改过时不写入，对话框里有说明。
3. 启动器写入新文件。
4. 这次改动记进 **历史**。

### 替换方块

替换方块是一张表，每一行“从 → 到”：

1. 打开 **替换方块…**：从头部的橙色键（第一行是最多的方块）、从材料详情的 **替换…**（这种方块的任意状态）、或从检视卡的 **替换…**（这个方块的状态，每个属性都精确匹配）。
2. 在左边选要替换的方块。打开 **不限属性** 时匹配它的每种状态；关掉时，每个属性选一个值或 **任意**。
3. 在右边选要换成的方块。列表是这份投影的游戏版本里的方块，最近用过的在前，可以搜索。
4. 要同时替换几种方块，点 **加一行**。各行一起按替换前的样子匹配，不会一行接着一行替换。
5. 在 **范围** 里选 **全部区域**、某个区域、**当前切片** 或选区。
6. 每行末尾写这一行会替换多少个，确认键写总数（例如“替换 128 个方块”）。点它写入。

换成的方块沿用被替换方块的同名属性（例如楼梯的朝向）。方块 ID 不变的方块保留它的方块实体数据。

要以后再用这张表：在 **方案** 里写一个名字，点 **存为方案**。方案存在启动器的数据里，所有游戏共用；在别的投影里用 **套用方案…** 选它。用方案替换时，历史里写明方案名。

### 转换版本

1. 在 **更多** 里选 **转换版本…**，或点头部的 **转换到 26.3…**。目标默认是这个游戏的版本。
2. 对话框先试着转换：
   - 转换到更新的版本不会丢失内容。
   - 转换到更旧的版本时，对话框把每处改动列成三组：**丢失**、**近似**、**保留**（目标版本没有的方块，按原样写出，在那个版本里读入时变成空气）。
   - 在 **保留** 组下点 **为这些方块选替代…**，替换方块打开，每种保留的方块一行，等你选要换成的方块。
3. 默认另存为同一文件夹里的“名 (26.3).litematic”，原文件不动，写完后选中新文件。打开 **覆盖原文件** 才写回原文件。
4. 点 **取消** 时不写入任何东西。

### 编辑信息

1. 在 **信息** 标签里点 **编辑…**，或在 **更多** 里选 **编辑信息…**。
2. 修改名称、作者或描述，然后保存。

名称不能为空。保存时更新修改时间，不改动方块数据。

### 重复的投影

**信息** 的 **重复** 一节列出与这份投影方块内容相同的文件。
启动器只比较方块内容，不比较文件名和元数据。

要只保留一份：在要保留的那一行点 **只保留这个**，然后确认。
同组的其他文件移进启动器的备份，不会真正删除。启动器从不自动删除重复的文件。

### 删除

在 **更多** 里选 **删除…**，然后确认。
文件移进启动器的备份，不会真正删除，可以在 **历史** 里恢复。

### 从历史恢复

1. 打开 **历史** 标签。每一行是一次改动：时间、操作、文件和摘要。
2. 在要撤销的那一行点 **恢复**，然后确认。

启动器先备份现在的文件，再把这次改动之前的备份放回原处。恢复本身也记进历史，所以恢复也可以再恢复。
那次改动是新写出的文件（例如另存的转换）时，恢复把这个文件收进备份，不会真正删除。

## 已知限制

- 只支持 Litematica 的 `.litematic` 文件。
- 工作室不能逐个放置或删除方块，只能按方块状态批量替换和编辑信息。
- 点选按整格判断，不按方块的实际形状；非整块方块和半透明方块可能选到相邻的格子。实体不能点选。
- 实体按游戏在那一刻（动画开始前）的样子画：唤魔者尖牙和浮漂不显示（游戏读存档时也不显示），潜影贝弹的外层光晕、TNT 的闪白与膨胀、末地水晶的光束不画。
- 替换时只沿用方块资源包里写到的属性；`waterlogged` 这类没有模型用到的属性不沿用，取默认值。
- 转换到更旧的版本时，旧版本不认识的属性按原样写入，在那个版本里读入时用方块的默认值。拿不到目标版本的方块表时，对话框会说明这些方块没有检查。
- 1.17 以前的版本，实体和方块实体的形状借用 1.17 的形状，贴图仍用各自版本的。
- 不支持资源包的动画贴图、着色器和自定义实体模型（CEM）。
- 26.2 及以后的版本里，告示牌上的文字不显示。
- 不同颜色的染色玻璃相邻时，它们之间的面不画。
- 半透明的实体部件只按实体由远到近排序，个别角度下可能叠错。
- Wayland 下不能捕获鼠标，请使用 Orbital。
- 备份不会自动清理。
