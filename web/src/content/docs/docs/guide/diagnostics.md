---
title: 诊断包
description: 导出诊断包，查看里面有什么、隐去了什么。
---

向别人求助或报告问题时，可以导出一个诊断包。
诊断包是一个 `.zip` 文件。启动器不会自动发送它，由你决定交给谁。

## 导出诊断包

1. 打开 **设置 › 关于**。
2. 在 **诊断包** 一行点 **导出…**。
3. 选择保存的位置。

保存好后，提示写明文件的位置。

## 诊断包里有什么

| 文件 | 内容 |
| --- | --- |
| `about.txt` | 启动器版本、操作系统和架构、游戏数量、账户数量 |
| `settings.txt` | 默认内存、界面偏好（语言、外观、主题、字体、壁纸、翻译等）、同时下载数、镜像数量和下载来源、游戏默认的窗口大小和全屏 |
| `java.txt` | 找到的每个 Java：版本、发行方、架构、是否停用、位置 |
| `instances.txt` | 每个游戏：ID、游戏版本、加载器和它的版本、是否装好、游玩时间 |
| `activity.txt` | 最近完成的 50 个任务和结果 |
| `logs/` | 每个游戏的 `latest.log`，和上次启动时游戏的输出 |
| `launcher/` | 启动器自己的日志，以及写满后换下的上一份 |

Java 参数、游戏参数和环境变量只记条数。
启动前、包装和退出后命令只记有没有填，不记内容。

## 隐去的内容

导出时，启动器把以下内容换成占位文字：

| 原内容 | 换成 |
| --- | --- |
| 每个账户的玩家名 | `<player>` |
| 每个账户的 UUID | `<uuid>` |
| 启动器的数据文件夹 | `<launcher>` |
| 你的用户文件夹 | `~` |

## 限制

- 用户文件夹以外的路径保留原样，例如装在系统文件夹里的 Java 的位置。
- 游戏日志可能记有聊天内容和服务器地址，它们不会隐去。
- 分享之前，可以打开 `.zip` 文件查看里面的内容。
