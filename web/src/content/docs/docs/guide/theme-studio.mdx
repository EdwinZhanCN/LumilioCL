从一套内置主题或你自己的主题文件开始，修改颜色、圆角和字体，预览会实时变化。
做好后下载 `.json` 文件，按[主题](/docs/guide/themes/#添加本地主题)里的步骤放进启动器。
预览用网站的元件拼出启动器的样子，和启动器里的实际效果接近，但不完全相同。
