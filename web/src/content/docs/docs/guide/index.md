本节说明如何使用启动器的各项功能。
每页说明适用范围、准备工作、操作步骤、结果和已知限制。

| 任务 | 阅读 |
| --- | --- |
| 在 Modrinth 和 CurseForge 之间切换，安装 CurseForge 整合包，补上只能在网站下载的文件，翻译简介 | [内容来源](/docs/guide/content-sources/) |
| 更换配色、圆角和字体，或制作自己的主题 | [主题](/docs/guide/themes/) |
| 在浏览器里制作主题并预览 | [主题工作室](/docs/guide/theme-studio/) |
| 查看 Litematica 投影，替换方块、转换版本、处理重复文件，从备份恢复 | [投影工作室](/docs/guide/schematics/) |
| 导出诊断包，查看里面有什么、隐去了什么 | [诊断包](/docs/guide/diagnostics/) |

其他功能的页面会逐步补充。
启动器已实现的全部用户路径见 [docs/ia/paths](https://github.com/EdwinZhanCN/LumilioCL/tree/main/docs/ia/paths)。
