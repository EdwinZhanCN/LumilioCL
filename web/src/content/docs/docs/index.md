## 文档范围

贡献文档是项目的贡献规范。
项目不使用独立的 `CONTRIBUTING.md`。

[功能文档](/docs/features/)将逐步补充各项功能的操作说明。
[WASM 插件文档](/docs/wasm/)说明当前限制。
目前不能独立安装第三方 WASM 插件。

## 统一术语

**Project Maintainer** 指参与项目工作的人员或 Coding Agent。
这个称谓不授予仓库权限。
**Coding Agent** 指能读取文件、修改代码和运行命令的软件。

英文文档使用 ASD-STE100 写作规则。
中文文档使用相同的清晰结构。
软件术语见[编写文档](/docs/contribute/writing/#技术术语)。
