Feature procedures will use this section.
The initial documentation contains installation and contribution procedures.

For current capabilities, read the [project overview](https://github.com/EdwinZhanCN/LumilioCL#readme).
For implemented user paths, read [docs/ia/paths](https://github.com/EdwinZhanCN/LumilioCL/tree/main/docs/ia/paths).

Each future feature page must state its supported scope.
It must describe the required input, procedure, result, and known limits.
Do not use a roadmap target as evidence of implementation.
