## Documentation scope

The contribution pages contain the project contribution rules.
The project does not use a separate `CONTRIBUTING.md` file.

The [feature reference](/en/docs/features/) will contain procedures for each feature.
The [WASM plugin reference](/en/docs/wasm/) identifies the current plugin limits.
Installable WASM plugins are not available.

## Read the terms

**Project Maintainer** means a person or Coding Agent that does project work.
The term does not give repository permissions.
**Coding Agent** means software that can examine files, change code, and run commands.

Instructions use ASD-STE100 writing rules.
Software names and commands use the [project technical terms](/en/docs/contribute/writing/#technical-terms).
