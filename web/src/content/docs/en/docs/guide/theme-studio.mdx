Start from a built-in theme or from your theme file.
Change the colours, corners, and fonts, and examine the preview.
Download the `.json` file, then add it to the launcher as [Themes](/en/docs/guide/themes/#add-a-local-theme) tells you.
The preview uses the parts of this website to show the launcher.
It is near to the launcher, but it is not the same.
