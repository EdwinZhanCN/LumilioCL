This section tells you how to use the launcher.
Each page gives the scope, the preparation, the procedure, the result, and the known limits.

| Task | Read |
| --- | --- |
| Change between Modrinth and CurseForge, install a CurseForge modpack, add files that you can download only on a website, or translate summaries | [Content sources](/en/docs/guide/content-sources/) |
| Change the colours, corners, and fonts, or make a theme | [Themes](/en/docs/guide/themes/) |
| Make a theme in the browser and examine it | [Theme studio](/en/docs/guide/theme-studio/) |
| Examine Litematica schematics, replace blocks, convert versions, find duplicate files, or restore from backups | [Schematic studio](/en/docs/guide/schematics/) |
| Export a diagnostics bundle, and see what it contains and what it hides | [Diagnostics](/en/docs/guide/diagnostics/) |

Pages for other functions will follow.
For all user paths in the launcher, read [docs/ia/paths](https://github.com/EdwinZhanCN/LumilioCL/tree/main/docs/ia/paths).
