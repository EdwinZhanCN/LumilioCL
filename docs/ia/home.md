# 首页

[返回 IA 索引](README.md) · ARCH：Home（Continue · Recent · Needs Attention） · 规则：design-language §5 · 流程：H-NAV-01/02、L-PLAY-01

首页不套用 §7 页面结构，它的视觉由世界场景主导。这里只列信息与路径。

## 信息层级

```
世界场景（全宽，状态驱动：展示 / 继续 / 启动中 / 游玩中 / 恢复）
  └ 前景：当前游戏名 · 版本·加载器·上次游玩 · [继续]（主要，场景上唯一亮色） [其他游戏 ⌄]
页面（场景下方）
  需要留意（有问题的游戏，每个一行 + 解决操作）
  最近（卡片行，最多 6 个；“查看全部” → 游戏库）
首次使用：一句话 + [新建游戏] [导入整合包]
```

- “继续”启动**当前游戏**（导航右段所选），不是“最近玩的”；两者在首次时相同。
- 启动中：按钮变块状进度条 + 阶段 + 取消；游玩中：“正在游戏中”+ 时长 + 结束游戏；失败：一句话 + 恢复并继续 + 技术详情（§5 已定义）。

## 用户路径

| 操作 | 结果 | 状态 |
|---|---|---|
| 继续 | 启动当前游戏 | ✅（跟随当前游戏，见导航） |
| 取消启动 / 结束游戏 | 停止 | ✅ |
| 恢复并继续 | 修复后重试 | ✅ |
| 打开最近的某个游戏 | 点最近卡片进游戏页（卡片有手型和悬停描边） | ✅ |
| 需要留意：解决 | 每个有问题的游戏一行：游戏名·最严重的问题·另有几个，一个按钮（安装/修复/更换…/去设置/去添加/查看日志…），点后先打开游戏页再执行 | ✅ |
| 空库：新建 / 导入 | 同游戏库 | ✅ |
