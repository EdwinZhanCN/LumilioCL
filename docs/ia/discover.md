# 发现

[返回 IA 索引](README.md) · ARCH：Discover（Modpacks · Mods · Resource Packs · Shaders） · 流程：L-DISC-01、L-CONT-01、L-LIB-03 · HMCL：H-DISC-01..05

## 定位

在 Modrinth 上找东西并装进当前游戏（整合包则装成新游戏）。入口：地标 ⌘3；游戏页内容“浏览 X”（带锁定目标）。

## 列表页信息层级

```
L1  发现 · 一行说明
L2  [⋯ 在 Modrinth 中浏览 · 重新搜索]
L3  整合包 | Mod | 资源包 | 光影                      [搜索 Modrinth]
L4  目标条（仅从游戏页进入时）：正在为「Ed's Vanilla」添加 Mod · 26.3 Fabric  [✕ 改为当前游戏]
    排序 ⌄ · 每页 ⌄ · 分页                              筛选栏（丝印编号：01 游戏版本 P-VERSION · 02 加载器 · 03 类别；加载器与类别是带 LED 的选项列表；清除筛选）
L5  结果目录（发丝线表格，顶部墨色粗线）：序号 · 图标（黑屏框）· 标题（细体）· 作者（大写等宽）· 简介 · 标签（加载器墨色，其余灰色）· 规格列 DL/FAV/UPD · [安装] / “已安装”
```

- 默认安装目标 = 导航当前游戏；从游戏页进入时 = 那个游戏（目标条可见、可清除）。
- 非整合包时，游戏版本与加载器筛选默认跟随目标游戏（可手动改），避免装上不兼容的东西。
- 行内“安装”：已装 → “已安装”芯片；装了旧版本 → “更新”。


## 用户路径

| 操作 | 结果 | 编号 | 状态 |
|---|---|---|---|
| 搜索 / 分类 / 筛选 / 排序 / 分页 | 结果列表 | H-DISC-01 | ✅ |
| 打开项目详情 | 详情页（进历史） | H-DISC-02 | ✅ |
| 安装（最新兼容版本） | 后台任务，toast“开始安装”，完成 toast | H-DISC-04 | ✅ |
| 安装指定版本 | 版本标签行内安装 | H-DISC-03/04 | ✅ |
| 安装整合包 | 新建游戏，完成后 toast 可“打开” | H-INSTALL-03 | ✅ |
| 依赖提示 | 安装 Mod 前，目标游戏还缺的必需依赖（最多 4 层，已装的不列）弹窗列出，默认勾选；没有适合版本的标明且不能勾；「只安装它」跳过依赖。查不出依赖时直接装 Mod。依赖先装，每个是动态里的一条任务 | H-DISC-03 | ✅（仅 Mod；弹窗里也列可选依赖（默认不勾）并警告与已装 Mod 不兼容） |
| 已安装状态 | 目标游戏已有的（按 Modrinth 识别）结果行显示「已安装」；有更新的显示「更新」，点了用新版本替换旧文件；详情页主按钮同样变化 | — | ✅（只认 Modrinth 认得的文件） |
| 另存为文件 | 版本行「另存为…」→ 选位置下载（任何类型，包括整合包文件） | H-DISC-05 | ✅ |
| 锁定目标（从游戏页进入） | 目标条：「正在为「X」添加 Mod · 版本 加载器」；从游戏页进入时多一个「✕ 改为当前游戏」，不改变当前游戏 | — | ✅ |
