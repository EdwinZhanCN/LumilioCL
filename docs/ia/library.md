# 游戏库

[返回 IA 索引](README.md) · ARCH：Library（All Instances · Favorites · User Collections） · 流程：L-LIB-01/02/03

## 定位

找到、整理、新建游戏。入口：地标 ⌘2；首页“查看全部”；导航“还没有游戏”。

## 信息层级

```
L1 页头    游戏库 · “N 个游戏”
L2 操作    [导入整合包]（次要） [新建游戏]（主要） [⋯ 导入其他启动器的游戏… · 从备份恢复… · 打开游戏库文件夹]
L3 工具栏  全部游戏 | 收藏 | 合集                     [搜索游戏]
L4 细化    排序 ⌄（最近游玩 / 名称 / 创建时间）  ·  加载器 ⌄（全部加载器 / 原版 / Fabric / …，仅库里出现过的；只有一种时不显示）
L5 内容    卡片网格（合集标签下：每个合集一节，节标题 + 卡片行）
L6 浮层    新建游戏弹窗 · 卡片右键/⋯菜单 · 删除确认 · 合集编辑弹窗
```

```
┌──────────────────────┐
│ 名称            Fabric│

│ │    像素封面       │ │
│ └──────────────────┘ │
```

- 点卡片 → 游戏页；点「启动」→ 启动（不打开游戏页）；点 ☆ → 收藏切换（图标颜色表示状态：灰色空星 / 橙色实心星）。
- ⋯ 菜单：开始游戏 · 打开 · 设为当前游戏 · 加入合集… · 复制… · 在访达中显示 · 导出整合包… · 删除…（危险，最后）。没有右键菜单：⋯ 菜单里有同样的操作。

## 新建游戏

**入口**：L2 主要按钮“新建游戏”；首页首次使用的“新建”。**组件**：`Dialog`，宽 480。

```
新建游戏                                        ✕
名称
[ Fabric 26.3                               ]   ← 留空时用占位文字作为名称（= 加载器 + 版本），随选择变化
加载器
( 原版 )( ◉ Fabric )( NeoForge )( Forge )( Quilt )   ← 单选分段
游戏版本
[ 26.3                                     ⌄ ]   ← P-VERSION
加载器版本                                          ← 选原版时整组隐藏
( ◉ 稳定版 0.19.5 )( 最新版 0.19.6-beta )( 其他 )
[ 0.19.4                                   ⌄ ]   ← 仅“其他”：P-LOADER-VERSION
☑ 创建后立即下载游戏文件  ⓘ
                                   取消   [创建]
```

规则：

- 字段顺序固定：名称 → 加载器 → 游戏版本 → 加载器版本。换加载器会保留游戏版本；若新加载器不支持该游戏版本，游戏版本区下方提示“X 还不支持 26.3”，并禁用创建（不自动换版本）。
- 名称重复允许（显示名与稳定 ID 分离，L-LIB-04）。名称不能全是空白（用占位名则不算空）。
- “创建后立即下载”默认勾选：创建成功后后台安装，进度在动态；不勾则只登记，首次启动时下载（L-LIB-02 第 3 步）。ⓘ：“先下载好，第一次启动更快；不下载也能玩，开始游戏时会自动补齐。”
- 提交：按钮转圈，弹窗禁用；成功 → 关弹窗、toast“已创建 X”、打开新游戏的游戏页、设为当前游戏；失败 → 留在弹窗，一句话 + 技术详情（例：“读不到 Fabric 的版本列表”）。
- 元数据（版本目录、加载器版本列表）任一读取失败：对应字段原位显示“读不到…”+ 重试，创建禁用；不提交错误配置。

状态与 core 前置：

| 部分 | 状态 |
|---|---|
| 版本目录与渠道标签（正式/快照/预发布/候选/远古） | ✅ |
| Fabric、Quilt 版本列表与“稳定/最新” | ✅ |
| Forge、NeoForge 版本列表 | ✅ |
| Forge、NeoForge 安装与启动（安装器处理器） | ✅（两者均实测进入游戏） |
| 创建（只登记）/ 创建并安装 | ✅ |

## 状态

- 加载：“正在读取…”。空库：“还没有游戏” + [新建游戏] [导入整合包]。收藏为空：“还没有收藏，点卡片上的星标收藏”。
- 出错：读不到游戏库 → 重试 + 技术详情。
