# 设置

[返回 IA 索引](README.md) · ARCH：Settings（General · Game Defaults · Java · Downloads） · ADR 0012 · 流程：L-SET-01、L-RUN-01 · HMCL：H-SET-01..15

## 定位

启动器本身与所有游戏的默认值。游戏自己的覆盖在游戏页·设置。

## 用户路径

已实现的设置项由代码里的 `// ia[settings]` 注释生成，见 [paths/settings.md](paths/settings.md)（约定见 ADR 0019）。下面“信息层级”里的表只描述每个标签页的版面。没做的：

- 语言：只有简体中文，设置页的“语言”行只是说明。
- 检查更新（启动器自动更新）：没有，“关于”里的“检查更新”行写明“暂未提供”；做它需要先写 ADR。

## 信息层级

```
L1  设置
L3  通用 | 游戏默认 | Java | 下载与存储 | 关于

```

### 通用

| 行 | 控件 |
|---|---|
| 外观 | 跟随系统 / 浅色 / 深色（分段） |
| 进入游戏后 | 保持 / 隐藏启动器（分段）；没有“关闭启动器”：启动器要守着游戏记录会话与游玩时间，关掉它游戏也会结束 |
| 游戏退出后回到前台 | 开关（默认开） |
| 减少动效 | 跟随系统 / 减少 / 完整（分段） |

### 游戏默认

| 行 | 值 | 编辑 |
|---|---|---|
| 最小 / 最大内存 | 最小 未设置 · 最大 4096 MB（弹窗说明本机内存与推荐值；恢复默认 = 推荐值） | 弹窗 |
| 窗口大小、全屏 | 1280 × 720 · 全屏 / 未设置 | 弹窗（宽高一起填；全屏 关 / 开 / 不设置） |
| Java 参数、游戏参数、环境变量 | 摘要 | 弹窗（每行一项；环境变量 名称=值） |
| 启动前 / 包装 / 退出后命令 | 摘要 | 弹窗（说明以当前用户权限运行与可用变量；启动前命令失败取消启动，退出后命令失败只记录） |

### 下载与存储

| 行 | 值 / 控件 |
|---|---|
| 优先使用镜像 | 开关 |
