# 动态

[返回 IA 索引](README.md) · ARCH：Activity（Downloads · Installs · Updates · Repairs） · 流程：L-OPS-01 · HMCL：H-TASK-01

## 信息层级

```
L1  动态 · “2 件事正在进行”
L2  [⋯ 清除已完成]
L3  全部 | 下载 | 安装 | 更新 | 修复
L5  进行中（置顶）  ● 标题 · 对象（哪个游戏）· 阶段          进度条 63% · 速度 · 剩余   [取消]
    已结束          ● 标题 · 对象 · 结果（完成/取消/失败） · 时间   [打开] / [重试] / [技术详情]
```

## 用户路径

| 操作 | 结果 | 状态 |
|---|---|---|
| 看进度 | 实时进度；速度和剩余时间在有两次读数后出现（下载按字节，安装/修复按文件个数） | ✅ |
| 取消 | 任务停止，状态“已取消” | ✅ |
| 打开结果 | 完成或失败的任务若关联到仍在游戏库里的游戏，有「打开」跳到游戏页；整合包安装/导入完成后关联到新建的游戏 | ✅ |
| 失败重试 | 失败或已取消的任务有「重试」，用当时的输入重新发起，作为新任务出现，旧条目保留 | ✅（升级前的旧记录没有输入，不显示） |
| 技术详情 | 失败原因弹窗 | ✅ |
| 分类筛选 | 按任务类别 | ✅ |
| 清除已完成 | 清空结束的条目 | ✅ |
| 导航角标 | 运行中任务数 | ✅ |
