# 全局导航

[返回 IA 索引](README.md) · 规则来源：design-language §6

## 定位

一直浮在窗口底部，回答三件事：**我在哪、我能去哪、我现在用哪个游戏和哪个身份玩**。

## 信息层级

```
导航栏（底部浮动，三段同一基线）
├── 左段：历史与位置
│   ├── ‹ 后退  （无处可退时置灰，不隐藏）
│   ├── › 前进
│   └── 当前位置名（地标名 / 游戏名 / “Mod 详情”等，超长截断，tooltip 显示全名）
├── 中段：地标胶囊（仅图标，tooltip = 名称 + 快捷键）
│   ├── 首页 ⌘1
│   ├── 游戏库 ⌘2
│   ├── 发现 ⌘3
│   ├── 动态 ⌘4（运行中任务数角标）
│   ├── 账户 ⌘5
│   └── 设置 ⌘,
└── 右段：游玩上下文
    ├── 当前游戏芯片：封面 + 名称 + ⇅ → 弹出列表
    └── 当前账户芯片：皮肤头像（仅图标，tooltip = 名字）→ 弹出列表
```

## 用户路径

| 操作 | 组件 | 结果 | 状态 |
|---|---|---|---|
| 后退 / 前进（按钮、⌘[ / ⌘]、详情页 Esc） | 图标按钮 | 回到上/下一个位置；位置 = 地标页、游戏页、项目详情；标签/筛选/滚动不进历史 | ✅ |
| 点地标 | 胶囊按钮 | 打开该页并清空“前进” | ✅ |
| 切换当前游戏 | `Popover` 列表：封面、名称、版本·加载器；当前项高亮；>8 项时顶部出现搜索 | 之后的“开始游戏”和发现页安装都指向它；已开始的操作不受影响 | ✅（当前游戏保存在 settings.json，重启后保持；首页“继续”跟随它；被删除时回落到剩余第一个） |
| 没有游戏时点芯片 | 文字按钮“还没有游戏” | 打开游戏库 | ✅ |
| 切换账户 | `Popover` 列表：头像、名字、类型（离线/Microsoft）；单选；底部“管理账户…”→ 账户页 | 之后的启动使用该身份 | ✅ |
| 没有账户时 | 芯片显示“添加账户” | 打开账户页的添加离线账户弹窗 | ✅ |

## 规则

- 页面不再画自己的返回按钮。
- 地标与当前上下文分开：地标是“去哪”，右段是“用什么玩”。
- 窗口最窄 720 px 时：位置名先截断到 120 px，再隐藏游戏名只留封面。
