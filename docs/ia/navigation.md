# 全局导航

[返回 IA 索引](README.md) · 规则来源：design-language §6

## 定位

一直浮在窗口底部，回答三件事：**我在哪、我能去哪、我现在用哪个游戏和哪个身份玩**。

## 信息层级

```
导航栏（底部浮动，三段同一基线）
├── 左段：历史与位置
│   ├── ‹ 后退  （无处可退时置灰，不隐藏）
│   ├── › 前进
│   └── 当前位置名（地标名 / 游戏名 / “Mod 详情”等，超长截断，tooltip 显示全名）
├── 中段：地标胶囊（仅图标，tooltip = 名称 + 快捷键）
│   ├── 首页 ⌘1
│   ├── 游戏库 ⌘2
│   ├── 发现 ⌘3
│   ├── 动态 ⌘4（运行中任务数角标）
│   ├── 账户 ⌘5
│   └── 设置 ⌘,
└── 右段：游玩上下文
    ├── 当前游戏芯片：封面 + 名称 + ⇅ → 弹出列表
    └── 当前账户芯片：皮肤头像（仅图标，tooltip = 名字）→ 弹出列表
```

## 用户路径

已实现的路径由代码里的 `// ia[navigation]` 注释生成，见 [paths/navigation.md](paths/navigation.md)（约定见 ADR 0019）。目前没有未做的路径。

## 规则

- 页面不再画自己的返回按钮。
- 地标与当前上下文分开：地标是“去哪”，右段是“用什么玩”。
- 窗口最窄 720 px 时：位置名先截断到 120 px，再隐藏游戏名只留封面。
