# 账户

[返回 IA 索引](README.md) · ARCH：Accounts（Offline · Microsoft） · ADR 0012 · 流程：L-ACC-01、L-ACC-02 · HMCL：H-ACC-01..12

## 定位

管理用来进入游戏的身份，并选一个作为当前账户。日常切换在导航右段的账户芯片完成；这里是完整管理。

## 信息层级

```
L1  账户 · “当前：Steve（离线）”
L2  [添加离线账户]（次要） [登录 Microsoft]（主要）
L5  列表
    ◉ [皮肤头像] Steve        离线账户 · UUID 前 8 位            当前   ⋯
    ○ [皮肤头像] Edwin_Zhan   Microsoft · 登录有效至 10-30             ⋯
L6  添加离线账户弹窗 · Microsoft 登录弹窗 · 删除确认 · 皮肤弹窗
```

- 单选圆点 = 选为当前账户（快捷操作，即时生效）。
- ⋯：复制 UUID · 更换皮肤…（离线）· 刷新登录（Microsoft）· ─ · 移除…（危险）。

## 弹窗

**添加离线账户**：名称（最多 16 位字母数字下划线，实时校验并说明原因）、UUID（高级选项，可空，默认由名称确定；格式 32 位十六进制，可带横线；与现有账户重复会被拒绝）→ 添加；首个账户自动成为当前。

**登录 Microsoft**：说明一句 → [在浏览器中登录] → 等待中（显示设备码与“复制”，可取消）→ 成功关闭并 toast；失败一句话 + 技术详情。

## 用户路径

| 操作 | 结果 | 编号 | 状态 |
|---|---|---|---|
| 添加离线账户（含自定义 UUID） | 列表新增；UUID 只在添加时可设 | H-ACC-02 | ✅ |
| 选为当前 | 之后启动使用 | H-ACC-06 | ✅ |
| 移除 | 警告弹窗；只删身份不删游戏 | H-ACC-08 | ✅ |
| 复制 UUID | 剪贴板 toast | H-ACC-09 | ✅ |
| 离线皮肤 | 弹窗：默认（Steve/Alex）/ 本地图片、模型 | H-ACC-11 | ⏸（ADR 0018 提议推迟：需要第三方认证范围和 authlib-injector） |
| Microsoft 登录 / 刷新 | 见上；失效的登录显示“需要重新登录”，菜单里“刷新登录” | H-ACC-01/07 | ✅（ADR 0013；真实登录需要 Mojang 批准应用注册） |
| 第三方认证（authlib-injector） | — | H-ACC-03/04/05 | ⏸ |

## 状态

- 没有账户：内容区“还没有账户，添加一个才能进游戏” + [添加离线账户] [登录 Microsoft]。启动时若没有账户，先弹出添加离线账户弹窗（H-PLAY-02），添加后继续启动；取消则不启动 ✅。
