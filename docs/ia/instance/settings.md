# 游戏页 · 设置

[返回游戏页](README.md) · ARCH：Instance.Settings（Game · Runtime · Java · Performance · Advanced） · 流程：L-SET-01、L-LIB-07、L-RUN-01 · HMCL：H-SET-08/09、H-INSTANCE-06

## 定位

只属于这个游戏的设置。每一项默认“跟随默认”（全局设置），覆盖后显示自己的值。所有自由输入都在弹窗里编辑（P-SETTINGS-GROUP、design-language §10）。

## 信息层级

```
L4  游戏 | 运行时 | Java | 性能 | 高级
L5  设置组（标题 + 列表块；行：标签 ⓘ … 值 / 开关 / [编辑]）
```

## 规则

- 每个弹窗都有“恢复默认”次要按钮（清除覆盖）。
- 运行中的游戏不受影响：保存后 toast“已保存，下次启动时生效”。
- 换版本/换加载器属于 L-LIB-07：绑定发起时的实例与输入，可能部分失败，必须可恢复。
