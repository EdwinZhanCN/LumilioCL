# 游戏页（实例）

[返回 IA 索引](../README.md) · ARCH：Instance · 流程：L-LIB-04..08、L-PLAY-01、L-CONT、L-WORLD、L-HIST、L-DIAG、L-SET

## 定位

一个游戏的一切：开始玩、管理内容和存档、看出了什么问题、调设置。入口：游戏库卡片、首页最近、导航当前游戏芯片（长按/菜单“打开”）、发现页安装完成 toast 的“打开”。

## 页头与操作（所有标签共享）

```
L1  [像素封面，铺满顶部并渐隐]
    名称                                         [开始游戏]（主要） [⋯]
    26.3 · Fabric 0.19.5 · 游玩 12 小时 · 上次游玩 3 天前 · ●需要留意（有问题时）
L3  概览 | 内容 | 世界 | 历史 | 诊断 | 设置
```

- 说明行是事实：版本、加载器、累计游玩、上次游玩。有问题时末尾加一个黄/红点短语，点击跳到“概览”的问题区。
- 主要按钮随状态变：未安装“下载并开始”、可玩“开始游戏”、启动中“正在启动…”（禁用，进度看首页/动态）、运行中“结束游戏”（危险描边）。
- 更多（⋯）：设为当前游戏 · 安装游戏文件（未安装时）/ 修复游戏文件 · 创建快照 · 复制游戏… · 完整备份… · 导出整合包… · 在访达中显示 · ─ · 删除游戏…（危险）。

| 操作 | 结果 | 编号 | 状态 |

| 设为当前游戏 | 导航右段切换 | H-NAV-03 | ✅ |

| 创建快照 | 弹窗：备注（可空）、范围（全部 / 仅存档）→ 后台 | L-HIST-01 | ✅（弹窗：备注、范围＝全部或某个世界） |

### 导出整合包（✅）

弹窗：格式（Modrinth .mrpack，或 MultiMC/Prism .zip）、名称、版本号、简介、包含哪些文件（默认：mods、config、resourcepacks、shaderpacks；不默认含存档和日志）→ 选择保存位置 → 后台导出 → toast。

现实现：勾选游戏目录的第一层条目，文件夹可展开单独勾选里面的文件（存档、日志不展开）；Modrinth 认识的 Mod/资源包/光影按地址列出（含 sha1/sha512），其余放进 `overrides/`；连不上 Modrinth 时全部放进包里，toast 会说明。导出是动态页里的一条任务，可取消（取消后不留文件）。
