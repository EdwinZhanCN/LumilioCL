# 游戏页 · 世界

[返回游戏页](README.md) · ARCH：Instance.Worlds · 流程：L-WORLD-01/02、L-PLAY-02 · HMCL：H-WORLD-01..12

## 信息层级

```
L4  [搜索 N 个世界]   排序：最近游玩 ⌄                       [导入世界]（次要）
L5  列表
    [世界图标] 名称                 生存 · 困难 · 作弊关        上次游玩 2 周前 · 820 MB     [▶ 进入] ⋯
L6  复制弹窗 · 删除确认 · toast
```

- 图标用存档自带的 `icon.png`，没有就用像素占位。
- “进入”直接启动游戏并进入这个世界（Quick Play），按钮是行内唯一的强调操作。
- ⋯：复制… · 创建备份（仅存档快照）· 导出为 .zip… · 在访达中显示 · ─ · 删除…（危险）。
- 游戏运行中：本启动器启动的游戏运行时，世界页顶部说明，复制/备份/导出/删除/导入/进入全部禁用；`session.lock` 在游戏开始之后被碰过且最新的那个世界标「正在游玩」（近似：游戏打开世界时会写这个文件，退回主菜单后仍会被当作在玩）。
- 现实现：行内保留「进入」「删除」（二次点击确认），复制/备份/导出/显示收在 ⋯ 菜单。
