## 用户路径

| 操作 | 结果 | 状态 |
|---|---|---|
| 看变更 | 只读时间线（内容、世界、设置、安装等） | ✅ |
| 看游玩记录 | 只读；崩溃或没能启动的会话有「查看日志」，跳到诊断·日志 | ✅（崩溃报告按时间对应：该会话开始到结束后 2 分钟内写下、离结束最近的那份，找到就直接打开） |
| 创建快照 | 弹窗：备注、范围 → 后台 → toast | ✅ |
| 恢复快照 | 警告弹窗：“恢复会用快照替换当前的 X，当前状态会先自动存一份” → 后台 → toast | ✅ |
| 删除快照 | 警告弹窗 | ✅ |
