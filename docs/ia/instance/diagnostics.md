# 游戏页 · 诊断

[返回游戏页](README.md) · ARCH：Instance.Diagnostics（Problems · Logs · Files） · 流程：L-DIAG-01、L-PLAY-01 · HMCL：H-PLAY-09/10、H-INSTANCE-10

## 信息层级

```
L4  问题 | 日志 | 文件
问题  列表：严重度点 · 一句话 · 原因 · [解决操作]（与概览“需要留意”同源，这里列全部）
日志  L4b  来源：[正在运行 / 最新日志 / 崩溃报告 2026-09-27 ⌄]   级别：全部 · 错误 · 警告 · 信息   [搜索日志]   [复制] [导出…] [⤢ 展开]
      L5   等宽日志视图（虚拟滚动，按级别着色，跟随末尾；崩溃报告上方先显示识别出的原因卡片）
文件  L4b  面包屑 游戏目录 / config /     [搜索文件]   [在访达中显示]
      L5   表格：名称 · 大小 · 修改时间 · ⋯（在访达中显示 · 复制路径）
```

## 用户路径

| 操作 | 结果 | 编号 | 状态 |
|---|---|---|---|
| 看问题、执行修复 | 每个问题一个操作（与概览相同） | L-DIAG-01 | ✅ |
| 看最新日志 / 崩溃报告 | 选择来源 | H-PLAY-10 | ✅ |
| 实时日志（游戏运行中） | 本启动器启动的游戏运行时，日志显示它正在输出的内容（最近 2000 行），自动跟随末尾，级别筛选/搜索/复制照常；游戏结束后改读 latest.log。启动器之外启动的游戏没有实时输出 | H-PLAY-09 | ✅ |
| 按级别筛选、搜索 | 视图状态（级别＝该级别及更严重；堆栈行跟随上一行的级别） | H-PLAY-09 | ✅ |
| 复制日志 | 复制当前筛选出的行 | H-PLAY-09 | ✅ |
| 导出日志 | 选位置保存最新日志或打开着的崩溃报告；玩家名、UUID、启动器目录、游戏目录、用户主目录都换成占位符 | H-PLAY-09、H-SET-15 | ✅ |
| 崩溃原因识别 | 原因卡片 + 建议操作 | H-PLAY-10 | ✅（`CrashHint`） |
| 浏览文件 | 逐级打开的只读文件夹列表，只在游戏目录内 | H-INSTANCE-10 | ✅（右上角按名字搜当前文件夹） |
| 在访达中显示 | 当前文件夹或所选文件 | H-INSTANCE-10 | ✅ |
