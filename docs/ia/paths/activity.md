| 暂停 / 继续 | 正在下载的任务行的「暂停」「继续」（同一个位置） | 暂停后放开连接、保留已下载的部分，状态变成“已暂停”、进度条变灰；继续后从已下载处接着下 | 任务开始下载后才出现 | `lumilio-ui/src/features/activity/view.rs` |
| 取消 | 运行中任务行的「取消」 | 任务停止，状态“已取消”；已下载的部分留到下次重试时继续 | 留下的部分启动时清理超过 7 天的 | `lumilio-ui/src/features/activity/view.rs` |
| 技术详情 | 失败任务行的技术详情 | 失败原因弹窗；下载失败写明每个试过的来源和它的原因 |  | `lumilio-ui/src/features/activity/view.rs` |
| 看下载详情 | 运行中任务行首的展开键 | 在任务下展开一张表：正在下载的每个文件、来源、几条连接（亮几格）、进度；某来源失败时写在那个文件下面，原因在技术详情里；排队的文件只数个数 | 任务开始下载后才出现 | `lumilio-ui/src/features/activity/view.rs` |
| 看进度 | 任务行：名字旁的状态，名字下的进度条，右侧的已下载/总量与其下的剩余时间 | 下载中、等待连接、进行中、已暂停一眼可分；进度条只会前进，暂停时变灰；剩余时间在有两次读数后出现（下载按字节，安装/修复按文件个数） |  | `lumilio-ui/src/features/activity/view.rs` |
| 看下载仪表 | 列表上方的显示屏 | 所有下载加起来的速度；每格一条连接，格数是设置里的同时下载数，亮几格就在用几条；进行中与已暂停的任务数 | 有任务在下载时才出现 | `lumilio-ui/src/features/activity/view.rs` |
| 清除已完成 | L2 次要「清除已完成」 | 清空结束的条目；没有结束的条目时禁用 |  | `lumilio-ui/src/features/activity/view.rs` |
