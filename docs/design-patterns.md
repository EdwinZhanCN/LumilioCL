# 共享模式与组件规范

跨页面复用的交互模式（P-…）。代码里的注释和测试引用这里的模式名，不重复描述。新增一种跨页面复用的交互时，先在这里定义。页面上有哪些用户路径见 [ia/paths/](ia/paths/README.md)；视觉和文案规则见 [design-language.md](design-language.md)。

## P-VERSION — 游戏版本选择器

凡是选择 Minecraft 版本的地方都用它：新建游戏、更换游戏版本、发现页版本筛选、导入时覆盖版本。

```
[ 26.3                         ⌄ ]   ← 触发器：显示当前值；本身就是搜索框（聚焦即可输入）
┌──────────────────────────────────┐
│ 26.3                         ✓   │  ← 列表项：版本号；当前值打勾
│ 26.2                             │     非正式版右侧带类型标签：快照 / 预发布 / 候选 / 远古
│ 26.1.2                           │
│ …                                │
├──────────────────────────────────┤
│ ◉ 显示所有版本                   │  ← 底部开关；打开后列出快照、预发布、候选、远古版本
└──────────────────────────────────┘
```

- **默认只列正式版**，最新的在最上。打开“显示所有版本”后按发布时间混排全部类型，每项带类型标签。
- **搜索**：输入即过滤，匹配版本号子串；搜到的若是非正式版，即使开关关着也显示（并带标签），避免“我明明输对了却找不到”。
- **默认值**：最新正式版。目录读取中显示“正在读取版本…”并禁用；失败时触发器内显示“读不到版本列表”+ 重试，不猜一个版本。
- 组件：gpui-component `Combobox`（可搜索下拉），列表底部放开关。
- 数据：core `VersionCatalog`（`CatalogEntry::kind`：Release / Snapshot / Old / Other）。core 需补一个把预发布、候选从快照里区分出来的标签函数（只用于展示）。

## P-LOADER-VERSION — 加载器版本选择

选了非原版加载器后出现，紧跟游戏版本之后（加载器版本依赖游戏版本）。

```
加载器版本
( ◉ 稳定版 )( 最新版 )( 其他 )        ← 单选分段
[ 0.19.5（稳定）               ⌄ ]   ← 仅“其他”时出现：P-VERSION 同款可搜索下拉，但没有“显示所有版本”开关
```

- **稳定版**：发布方标为稳定的最新一个（core `loader::recommended`）。**最新版**：列表第一个，可能不稳定。两者都在旁边以只读文字显示实际版本号，让人知道会装什么。
- **其他**：下拉列出该游戏版本下的全部加载器版本，每项标“稳定/测试”。因为“稳定版/最新版”已经覆盖了过滤语义，这里不再提供“显示所有版本”。
- 游戏版本改变时重新获取；当前选择若不存在则回到“稳定版”。该游戏版本没有任何加载器版本时，整个加载器版本区显示“这个版本还没有 X”，并禁用创建。
- 组件：`TabBar::segmented` + `Combobox`。

## P-CONTENT-ITEM — 内容条目（Mod / 资源包 / 光影）

```
☐ [图标] 标题                       版本号              ⇆  ◐  🗑  ⋯
         作者 · 来源标记             文件名.jar
```

| 区域 | 内容 | 规则 |
|---|---|---|
| 选择框 | 批量选择 | 勾选后出现 P-BULK |
| 图标 | Modrinth 项目图标 | 识别不到时用确定性像素占位（同种子） |
| 标题 | Modrinth 项目名 → 文件内元数据名 → 文件名（去 `.disabled`） | 能点：已识别 → 打开该项目详情；未识别 → 无动作 |
| 作者 | Modrinth 作者 → 元数据作者 | 未识别时显示“本地文件” |
| 版本 | Modrinth 版本号 → 元数据版本 → “未知” | |
| 文件名 | 实际文件名 | 次要文字，截断，tooltip 全名 |
| ⇆ 切换版本 | 打开 P-VERSION-SWITCH | **仅识别到 Modrinth 来源时出现**；有更新时变为“更新”强调样式（↑ + 主色） |
| ◐ 开关 | 启用/停用 | `Switch`，即点即生效（快捷操作） |
| 🗑 删除 | 删除文件 | 警告弹窗确认 |
| ⋯ 更多 | 在访达中显示 · 复制链接（仅已识别）· 打开项目页（仅已识别）· 固定版本 | 固定版本的条目不参与“全部更新” |

- 识别：按文件 SHA-1 向 Modrinth 查询（core `updates::identify`）；结果按哈希缓存，离线时用缓存，缓存没有就当未识别。识别失败不影响列表显示。
- 停用的条目整行降低不透明度。

## P-VERSION-SWITCH — 切换 / 更新版本弹窗

“更新”和“切换版本”是同一个弹窗，只是默认选中的版本不同。

```
┌ [图标] 切换版本 · AppleSkin ────────────────────────── ✕ ┐
│ [搜索版本…]           │ 3.0.11+mc26.3   正式   2026-09-02 │
│ ● 3.0.11+mc26.3 新    │ Fabric · 26.3                      │
│   3.0.10+mc26.2 当前  │ ─────────────────────────────────  │
│   3.0.9+mc26.1  ⚠     │ 更新日志（Markdown）                │
│   …                   │                                    │
│ ◉ 显示不兼容的版本     │                                    │
├───────────────────────┴────────────────────────────────────┤
│ ⚠ 换版本可能让游戏出问题，必要时先建快照       取消  [切换到 3.0.11] │
└────────────────────────────────────────────────────────────┘
```

- 左栏：版本列表（版本号、渠道标签 正式/测试/内测、“当前”“新”标记），顶部搜索，底部“显示不兼容的版本”开关；不兼容项带 ⚠ tooltip 说明原因（游戏版本/加载器不符）。
- 右栏：选中版本的详情（版本号、渠道、日期、支持的加载器与游戏版本、更新日志）。
- 入口语义：点“更新”打开时默认选中最新兼容版本；点 ⇆ 打开时默认选中当前版本（主按钮禁用，直到选了别的）。
- 主按钮文案：“更新到 X” / “切换到 X”（降级也叫切换）。执行时弹窗保持、按钮转圈；成功关闭并 toast；失败留在弹窗里显示一句话（§10、§11）。
- 底部提示建快照，带“先建快照”次要链接（✅ 更换版本的弹窗里有）。
- 数据：Modrinth 项目版本列表（core discover 已有）；应用：core `updates::apply` 的“下载新文件 → 校验 → 删除旧文件”语义，扩展为可指定任意版本。

## P-BULK — 批量选择栏

列表里勾选任意条目后，替换列表上方的工具栏（同样高度，列表不跳动）：

```
[已选 3 项 · 清除选择]          启用   停用   更新   删除
```

- 只放能批量做的操作；删除标红并确认。逐项返回结果，部分失败时 toast 写“2 项完成，1 项没有成功”+ 技术详情。
- 表头选择框：全选 / 全不选；搜索或筛选后全选只作用于可见项。

## P-ADD-FILES — 添加本地文件

- 入口：页面次要操作“添加文件”（系统文件选择器，可多选）＋把文件拖进列表区域（拖入时整块高亮“松开以添加到 X”）。
- 按扩展名分配到对应文件夹；不认识的文件逐项列出“已跳过”。同名不同内容不覆盖，返回冲突（core 规则）。

## P-SETTINGS-GROUP — 设置组

- 一组 = 分组标题 + 一个列表块；组标题右侧可放“编辑”（成组编辑时）。
- 行：标签 + ⓘ（帮助）在左；只读值、开关、下拉在右；文字/数字/路径/参数类在右侧放“编辑”。
- “跟随默认”是一种值：显示为“跟随默认 · 4096 MB”。编辑弹窗里每个字段旁有“跟随默认”复选，勾上即清除覆盖。

## P-CONFIRM — 确认

- 删除、恢复、覆盖等不可逆操作：`AlertDialog`，标题“删除 X？”，一句后果，确认按钮为危险色。
- 可逆的快捷操作（开关、选择）不确认。

## P-STATES — 加载 / 空 / 出错

- 加载：内容区显示“正在读取…”（列表用骨架行，≤3 行）。
- 空：一句话 + 一个能解决它的主按钮（例如“还没有 Mod” + “浏览 Mod”）。
- 出错：一句话 +「重试」+「技术详情」。
- 都只替换内容区（L5）。

## P-ICON — 图标与占位

- 实例：确定性像素封面（`lumilio-ui::cover`）；未来支持自定义图片（⏸）。
- 项目：Modrinth 图标；无图标或加载失败用同种子像素占位。
- 账户：皮肤头像（离线账户用默认皮肤按名字确定 Steve/Alex 等）。
